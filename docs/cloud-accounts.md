# 账户与云端简历

这次功能增加账户、可选云端保存和管理员用户配额管理。浏览器本地数据库 `myresume-local-v1` 保留原有结构，旧简历不会在登录时自动上传。

网站名称为 SparkShark，正式域名为 `https://sparkshark.sharmoon.cc.cd`。新域名与原 `me.sharmoon.cc.cd` 的 IndexedDB 按浏览器来源隔离，不能直接读取旧域名的本机简历。应从旧地址导出 JSON 备份后在新地址导入，详见 [域名迁移](domain-migration.md)。

## 保存位置

- 新建、复制和导入简历时显示“仅保存在本机”和“保存到云端”，默认选择本机。
- 选择云端后才要求登录。上传失败或取消登录时，本机简历保留，界面提示云端尚未保存并提供重试。
- 云端简历保存当前可编辑内容及其引用照片。字体、缩略图、PDF 和浏览器中的历史版本不会随当前简历上传。
- 云端简历编辑后自动提交已在本机保存的版本。两个设备发生版本冲突时保留本机修改，由用户决定如何继续。
- 云端关联记录包含所属账户。退出或切换账户时，其他账户的云端缓存不会出现在当前账户工作区，也不能直接通过编辑路由打开。

## 账户与管理

- 访客可以自行注册用户名和密码；显示名称为选填。
- 新账户默认可云端保存 10 份简历。管理员可以调整单个账户的上限及新账户的默认值，并开关公开注册。
- 管理员可查看用户、账户状态、保存份数和简历与照片容量，停用或恢复用户，并重置其他用户的密码。
- 下调配额不删除既有简历，用户仍可编辑或删除已有云端简历；新增保存受配额约束。
- 管理员界面仅提供用户和容量统计，不提供他人简历正文浏览。
- 第一位管理员通过受一次性部署凭据保护的初始化接口创建，普通访客注册不会获得管理员权限。

## 数量与容量的口径

“份数”指账户当前保存的云端简历记录。照片不增加份数；本机回收站、PDF 导出和本地历史不会增加云端份数。删除云端记录才会释放对应的云端名额。

界面的容量为服务端计算的正文 JSON UTF-8 字节数加照片原始二进制字节数。它不等于整个数据库文件大小，数据库表和索引也有额外开销。上传过程使用的 Base64 不作为持久化照片格式。

服务端默认限制每份正文不超过 512 KiB、引用照片不超过 5 MiB、单次请求不超过 8 MiB。限制只影响云端上传，失败时本机内容继续保留。

单份简历大小的合成测量见 [容量测算](cloud-size-assessment.md)。

## 运行与上线

前端使用静态文件，首选账户与保存 API 为 Cloudflare Free + SQLite Durable Objects，保留普通用户名和密码登录。2026 年 11 月 5 日，在账户套餐确认为 Workers Free/US$0 的独立测试站完成 10 组、68 次 API/字体操作验证，没有 HTTP 5xx。注册、登录、修改密码、账户隔离、同源/CSRF、管理员配额与并发最后名额检查通过；恰好 5 MiB 的照片往返哈希和逻辑容量一致。

正式 SparkShark 域名已启用 HTTPS，生产管理员已初始化，初始化 secret 已移除。新域名通过 7 组、42 次 HTTP 操作，没有 HTTP 5xx，包含注册登录、保存/读取/编辑、隔离、配额、照片和字体检查。浏览器已确认 SparkShark 名称和新建默认本地选择；完整浏览器账户交互、PDF 导出、CPU 指标和长期负载仍待验收。旧域名的本机简历不会自动迁移；测试站使用独立域名和数据。

开发和部署步骤见 [Free 后端说明](../cloud/free/README.md)，额度与容量见 [免费托管方案](free-hosting.md)。原 D1 Worker 与 [Node + SQLite 后端](../cloud/node/README.md) 保留为其他运行方式。GitHub 登录尚未接入，源码仓库不保存用户简历；没有购买或升级托管套餐。
