# 编辑器字号与分栏修正

2026-11-05。

## 界面比例

参考项目内保存的 TalenCat 页面设置实测图，桌面编辑区和预览区采用等宽布局。1440px 窗口下，224px 导航之后两个区域各为 608px。模块标题为 16px，页面设置标题为 18px，主要标签为 12px，输入与正文编辑文字为 14px；字号数值框宽 80px、高 36px。保留现有窄屏编辑／预览切换。

## 模块字号

未设置独立字号时，输入框直接显示页面字号，并标记“跟随页面”。仅聚焦或失焦不会把继承值固定下来；手动设置后可通过清空或“跟随页面”恢复继承。输入过程允许暂时清空，失焦时提交和校正范围，避免重打字号时被默认值打断。示意图、PDF 和 HTML 的自定义字段使用同一字号规则；次要文字只改变颜色。

## 思源黑体

TalenCat 公开字体样式使用 `Noto Sans SC`，与 Adobe／Google 思源黑体项目同源。新增“思源黑体”选项，正文采用原生 Medium（500）轮廓，粗体采用 700，另提供实际倾斜轮廓。来源、许可证、原生字重映射和文件哈希见 `public/fonts/manifest.json` 与字体说明。字体变体使用独立内部名称，原黑体选项继续保留。

## 单栏顺序与智能一页

单栏把旧数据中的主栏和侧栏按当前阅读顺序合成连续列表。箭头、拖动和跨页移动都使用该列表的索引；内容编辑区跟随同一顺序。单栏不显示侧栏区域、跨栏按钮、侧栏位置、栏宽和列间距。

智能一页保留当前单栏／双栏模式、模块所属栏及顺序、栏宽、侧栏方向和列间距，仍可合并手动分页、调整留白、字段间距、边距、字号和行高。收紧和铺满均以实际 PDF 测量结果判定。

## 核验

- 单元测试覆盖旧单栏数据跨原侧栏边界移动、分栏切换、页面移除、继承字号、HTML 字号以及智能一页每次测量的分栏约束。
- 浏览器验证 16→17px 继承、18px 独立设置、清空重打 20px、恢复继承、保存重开；单栏箭头、键盘拖动、跨页移动和刷新后的顺序一致。
- 1440px 桌面两区等宽；390px 窄屏弹窗及全部字段没有横向溢出。
- 六款字体的四种样式完成 PDF 字形与文件哈希检查。浏览器实际下载使用思源黑体；17px 公司字段测得 12.75pt，页面内文字无越界。
- 四个实际 PDF 收紧样本和六个铺满样本通过内容、分栏、还原及重复操作检查。
