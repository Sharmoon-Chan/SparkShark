# 第三阶段：编辑交互与保存反馈

2026-11-06 完成本地验收并按功能提交，已于 2026-11-07 随 [即时预览版本](releases/2026-11-07-instant-preview.md) 推送和发布。总计划见 [产品优化计划](product-polish-plan.md)，原始本地数据见 [阶段 3 量化记录](measurements/editor-stage3-2026-11-06.json)。

## 实现与操作变化

- 模块标题旁增加新增入口，底部和菜单入口保留。新增／复制自动展开、滚动到条目并聚焦首字段；副本保持相邻，使用独立 ID。已有条目刷新后默认折叠。
- 条目菜单增加上移／下移，首末边界禁用。隐藏条目和模块都有撤销；删除仍先确认、保存历史，并支持撤销。
- 完成编辑先等待本机保存。失败保持展开与当前输入，成功折叠并返回条目标题；再次编辑期间产生的新修改不会被误当作已保存。
- 常用颜色、密度、字体、字号和行高直接可见。低频排版和头像外观分别折叠，摘要展示当前值；折叠不会重置数据。Enter／Space 展开收起，Tab 跳过隐藏字段。
- 本机保存与云端同步分别表达。待同步提供立即同步；本机失败、云端失败和版本冲突均有持续恢复入口。本机状态在手机端也能打开详情，下载的草稿包含尚未保存的修改。
- 云端确认时固定账号和当前简历范围，等待本机存储期间切换账号或离开页面会停止原操作。错误提示中的重试窗口保持到操作结束，避免状态转为同步中就消失。

以鼠标激活计、不包含输入文字和滚动：从模块标题新增到首字段可输入为 1 次；从折叠条目复制到副本首字段可输入为 2 次（菜单、复制）。之前复制后还需展开副本并聚焦字段。菜单移动为 2 次，错误横条下载当前草稿为 1 次。这里记录操作路径，不是用户完成时间实验。

## 验收范围

浏览器脚本使用隔离会话和虚构简历，原始截图、下载文件在忽略目录 `output/playwright/`。通过项目和环境以结构化记录为准。

- `content-stage3.js`：新增与复制焦点、独立副本、排序边界、隐藏／删除撤销、本机写入失败保持展开、重试、刷新、375px 无溢出。
- `appearance-stage3.js`：原生折叠的 Enter／Space／Tab、字段值保持、摘要更新、移动端展开。
- `save-stage3.js`：模拟 IndexedDB 配额错误；验证 JSON 包含未保存内容；重试恢复；手机详情关闭后的焦点。Vite 开发环境注入云端显示状态，验证待同步、失败和冲突入口，远端写请求为 0。
- `conflict-stage3.js`：两个真实浏览器标签页竞争保存同一虚构本机简历，关闭弹窗后仍可恢复、另存副本并刷新验证内容。
- `cloud-status-stage3.js`：暂停本机读取后切换虚构账号或导航，验证不创建错误关联；错误转同步中时确认窗口保持。所有 API 拦截，不代替真实云端集成测试。
- `measure-stage3.js`：固定样本页面设置高度、控件数量、桌面／375px 截图。
- `menu-focus-stage3.js`：菜单新增和复制后的输入焦点、375px 模块排版图标、桌面与手机截图。

33 个单元测试文件、206 个测试通过；保存文案补充断言后针对性 3 个测试复跑通过。类型检查及最终生产构建通过。开发环境的条目、设置、故障恢复、云端作用域检查通过；生产构建补测条目完整流程、设置键盘操作、真实双标签冲突、菜单焦点及移动图标均通过。截图完成视觉复查。生产构建中的接口错误仅来自未配置的本地 `/api/auth/me`。

审查中发现并修复了两处云端交互问题：异步等待后才捕获账号造成的跨账号关联，以及 notice 状态变化导致提交窗口卸载。生产构建复查还发现菜单自动返回焦点会抢走副本输入焦点；使用菜单关闭事件协调焦点，避免只依赖动画帧时序。视觉检查发现旧窄屏规则隐藏了模块排版图标，已修复并在生产构建核验。

## 后续边界

本阶段的原始验收只覆盖本地，不含真实账号上传；后续发布与线上结果另见发布记录。本地 `/api/auth/me` 无代理后端会返回错误，不作为云端功能通过的依据。生产构建保留已有 `fflate`／`html.ts` 动静态导入重叠警告，不影响构建成功。
