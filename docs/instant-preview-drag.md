# 即时预览字段拖动

2026-11-07。按用户要求将精确 PDF 的字段拖动接入即时预览，完成副作用核验后已发布。

范围：同一模块、同一条目内的字段前后／上下重排，结果沿用 `contentLayout` 并应用到该模块全部条目；正文独占行。模块跨栏／跨组仍使用布局设置。

方案：只在拖动模式生成字段标记，从分页后可见 DOM 测量坐标，在 iframe 外叠加现有拖动层；不向 iframe 开放脚本。关闭模式不收集字段坐标。保留普通点击定位、键盘位置菜单、Escape 取消、自动滚动；内容、字体、分页或缩放变化时取消过期手势。

验证：开关模式的内容／布局一致、默认与自定义字段、双栏和跨页裁剪、30%／100% 缩放、正文禁用同行、取消与撤销、保存刷新、PDF 导出保持、字体加载中坐标失效、普通编辑与拖动模式更新耗时。使用合成简历，不编辑用户简历内容。

参考：[MDN Range.getClientRects](https://developer.mozilla.org/en-US/docs/Web/API/Range/getClientRects)、[Pointer capture](https://developer.mozilla.org/en-US/docs/Web/API/Element/setPointerCapture)。

## 实现

新增一个按需加载的 HTML 字段叠层，复用 PDF 模式的指针捕获、位置菜单、邻近命中区域和边缘自动滚动。源 HTML 只在拖动模式添加字段身份标记；非交互的 HTML 导出不包含标记。字体、内容、分页或缩放变化会撤销旧手势和位置菜单；坐标准备期间暂停操作。拖动工具下载失败给出重试入口，不影响已填写内容。

坐标取分页后每个页面／栏的实际可见区域，将被裁剪的长字段分别映射到所属物理页，并转换成现有拖动层的点单位。默认模板的混排说明按字段添加透明标记，保留原有文字、分隔符及样式；开启模式不自动转换为自定义布局。只有实际放置字段才写入 `contentLayout`，支持即时撤销。没有增加简历数据字段或扩大 iframe 权限。

## 本地验收

- 16 模板、9 种分页压力样本及全字段配置样本，共 26 组：开关拖动模式后文字、行数及页数一致，字段坐标不越过页面或所在栏，截断行数为 0。空白简历模式切换也完成无字段测量。字体切换完成后字段坐标更新。
- 默认合成示例共 36 个可操作字段。30% 缩放下实际将专业拖到学校右侧，两者纵坐标相等；100% 缩放下点击准确打开学校位置菜单。Enter 打开菜单，Escape／取消关闭后焦点返回字段。正文目标只有上下换行选项，撤销与保存刷新正常，刷新默认关闭拖动模式。
- 2 页／10 页样本各 20 次运行时更新，字段测量本身的中位数／p95 为 0.8／1.5ms 和 3.2／4.3ms，模式关闭为 0。完整帧等待混入 Chrome iframe 的后台节流（约 2–3 秒），不用于评价实际编辑性能或宣称加速；原始值保留并明确排除。
- 217 项单元测试通过；字段身份、隐藏／空条目、边界裁剪、模式关闭无标记与所有模板文字完整性有针对性覆盖。现有异步字体测试改为不依赖常规／粗体下载完成顺序。
- 27 组既有 PDF／HTML、73 页 PDF、191 次模块文字比对全部通过，PDF 字体与导出未改变。
- 带真实合成头像的超长页眉另行补测：5 页、36 个字段、截行数为 0；图片完成加载后坐标正常。
