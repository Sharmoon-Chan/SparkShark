# 模块内部排版

2026-11-03。每个模块右上角及模块菜单提供“模块内排版”。设置按模块保存，该模块的所有条目使用相同字段排列。

也可以在预览中开启“拖动布局”直接拖动文字：左右为同行前后，上下为另起一行。左右拖放后的字段按文字实际宽度紧排，例如专业紧接学校；其他行的边界保留。操作说明见 [预览拖动字段](preview-field-drag.md)。

## 操作

- 拖动手柄或使用上下箭头调整字段顺序。
- 选择另起一行或与上一字段同行；同行字段分列显示，未填写的字段不占位置。
- 文字字段可设置靠左、居中、靠右，及正常、加粗、次要样式。
- 字段可设置 8–36px 字号，留空跟随页面字号及默认比例；指定字号使用准确的 px 值。斜体和下划线可独立开启。
- 显隐只影响显示，保留原字段内容。
- 行间距与条目间距分别设置；富文本独占行，保留原来的段落和文字格式。
- 正文也支持独立字号、整字段斜体和下划线，原有的局部加粗、删除线、链接等继续保留。
- 修改先保存在对话框草稿，点击“应用排版”后生效；取消放弃草稿。选择“恢复模板排版”并应用即可还原。

## 保存与渲染

`SectionBase.contentLayout` 是可选配置，旧简历无需迁移。未设置的模块沿用模板原有排版。自定义字段新增时补入默认排列，删除或隐藏定义时忽略旧引用；复制与备份恢复同步重映射自定义字段 ID。历史记录显示中文排版差异。

PDF 和 HTML 使用相同的字段分组和值。隐藏字段不参与字体检查及导入标记提醒；全部字段隐藏的模块不留下标题或额外的空手动页。短条目和标题保护仍保留，长正文按原有完整行规则分页。

## 核验

69 个 Vitest 用例、类型检查及生产构建通过。新增测试覆盖可选配置校验、自定义字段引用、备份与历史往返、隐藏问题字符、数值等级及空模块过滤。

浏览器使用虚构示例：取消后行间距仍为 4；实际拖动把详情移到网址前，调整职位顺序、右对齐地点、隐藏网址、行间距 3 和条目间距 6 后，保存刷新保留全部设置。实际下载的两页 PDF 中职位在公司之前、网址隐藏，无超出 A4 的文字。恢复模板后字段回到默认顺序、间距为 4／8、网址重新显示。

`scripts/verify-content-layout.ts` 生成单栏、双栏、长正文、正文先于其他字段及隐藏字段样本。`scripts/verify-content-layout-pdfs.py` 核验字段顺序、地点位置、隐藏成绩、富文本居中与加粗、跨页内容和坐标。每份长正文的 144 次完整测试句均保留。

```powershell
pnpm test
pnpm build
pnpm exec tsx scripts/verify-content-layout.ts
python scripts/verify-content-layout-pdfs.py
```

最后一步需要 `pdfplumber`。实际 PDF、HTML、区域坐标、检查报告和交互截图位于 `output/content-layout/`。
