# 页面默认与智能铺满

2026-11-04。页面密度默认值参考 TalenCat 的编辑体验，并在本项目智能一页中加入不足一页时自动铺满。

## 默认设置

| 密度 | 正文字号 | 行高 | 外边距 |
| --- | --- | --- | --- |
| 紧凑 | 12.75px | 1.35 | 14px，约 3.7mm |
| 标准 | 14px | 1.5 | 18px，约 4.8mm |
| 宽松 | 15px | 1.65 | 24px，约 6.4mm |

外边距和字号使用 px，界面同时显示外边距的 mm 换算。新建、示例、密度选择及恢复默认采用上表数值。恢复默认使用当前模板的字体与配色；已有简历可点击“标准”套用新预设。预设在 [领域配置](../src/domain/registry.ts) 中定义，并由相应领域测试核验。

## 智能一页

同一个“智能一页”入口自动选择收紧或铺满。多页先优化分页和布局，再调整留白、边距和文字；只有一页但未满时，先展开段落及模块间距，再调整字号和行高，必要时单独微调其中一项。收紧后若仍有空白，会在同次操作继续铺满。

每个候选通过真实 PDF 页数和字段位置判定。页码不参与正文占用，保留页码区域；铺满目标为可用页高的 96.5%，扩展时去掉最后模块后的多余留白。正文自动放大最多至 18px、行高最多至 2、留白最多至 3 倍，已有更大的字号保留。很少的内容只在这些范围内适度展开，不制造巨大文字或删改内容。

全部字段、同行换行、对齐、显隐、模板、字体家族、颜色、照片和边距保留。变更支持一键还原，后续文字编辑继续保留；已铺满的一页再次点击保持原版。进度中可以取消。最多 20 次收紧测量、额外 16 次铺满测量。

## 实际核验

120 个 Vitest 用例、类型检查及生产构建通过。

| PDF 样本 | 调整前 | 调整后 | 字号／行高 |
| --- | --- | --- | --- |
| 单栏 | 59.2%，一页 | 96.6%，一页 | 14.5px／1.55 |
| 自定义字段 | 56.9%，一页 | 97.5%，一页 | 15px／1.6 |
| 深色双栏 | 48.3%，一页 | 97.1%，一页 | 16.75px／1.8 |
| 渐彩双栏 | 53.9%，一页 | 97.1%，一页 | 15px／1.65 |
| 手动分页 | 两页 | 96.6%，一页 | 14.5px／1.55 |
| 少量内容 | 17.9%，一页 | 35.4%，一页 | 18px／2，保留适度展开结果 |

每对 PDF 的非空白字符和照片一致，全部结果仍为一页，没有 NUL 或超出 A4 的字符；三种密度的实际左边距与配置相符。已检查真实渲染图，所有样本都通过还原及重复操作检查。原有四个多页收紧样本也回归通过。

界面中验证三种密度、把 16px 恢复为当前 Essential 的 14px 宋体与 18px 边距、智能铺满、重复点击、PDF／JSON 下载、一键还原及保存刷新。实际下载前后的 388 个非空白字符及照片一致，还原后的备份与调整前一致。

```powershell
pnpm test
pnpm build
pnpm exec tsx scripts/verify-page-defaults-and-fill.ts
python scripts/verify-page-defaults-and-fill.py
pnpm exec tsx scripts/verify-smart-one-page.ts
```

Python 检查使用 pdfplumber、Pillow 和 Poppler。输出位于 `output/page-defaults/`，其中 `report.json` 为实际测量，`content-report.json` 为 PDF 比对，`browser-report.json` 为界面记录，`browser-after.png` 为界面截图。实际 PDF、备份、默认边距对照及铺满前后对照在同目录。
