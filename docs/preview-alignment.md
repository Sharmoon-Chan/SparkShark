# 预览拖动中的分层对齐

2026-11-07。为即时预览和精确 PDF 的拖动模式加入靠左、居中、靠右，并明确每种选择的作用范围。

## 操作与范围

开启「拖动布局」，在纸张上方选择「拖放后对齐」和「应用到」，再移动字段。默认保持原对齐。点击字段或按 Enter，可打开「调整字段」对话框，选择「仅应用对齐」或移动并应用对齐。

| 范围 | 结果 |
| --- | --- |
| 字段内文字 | 在字段分配的区域内对齐。紧邻排列的文字会分配可伸缩的区域；富文本使用独立的段落对齐设置。 |
| 当前行整体 | 将当前行的字段作为一组，放在所属栏内容区的左侧、中间或右侧。窄栏换行后的每行仍按该规则排列。 |
| 本模块所有行 | 设置本模块每行的默认对齐，并清除单独的行对齐；随后仍可覆盖其中一行。模块标题继续使用模板样式。 |

同一模块的所有条目共用字段排版。行对齐保持在当前栏内。「模块内排版」面板同步显示字段、行与模块的选择。对齐后可通过通知中的「撤销」恢复；设置面板的「取消」保留已保存的排版。

## 分阶段实现

1. 数据规则：在已有 contentLayout 中增加可选 rowAlign、paragraphAlign。解析、复制、历史、备份和云端校验共用同一结构，旧简历无需迁移。对齐操作只修改排版元数据。
2. 渲染：HTML 和 PDF 分别处理字段内部的 text-align 与整行的 flex 对齐；整行模式释放日期的自动左外边距。PDF 的整行间距改用 gap，避免换行后的末尾外边距影响居中。富文本列表的标记与首段一起对齐。
3. 交互：即时预览与精确 PDF 共用工具栏和字段对话框，保留移动、键盘操作、撤销与自动保存。只有一个正文字段的模块也能单独设置对齐。字段仍存在时，缩放或坐标刷新保留对齐对话框。
4. 验收：先运行合成样本的坐标与内容检查，再通过浏览器操作验证，最后分批提交和 Cloudflare 发布。

行覆盖优先于模块默认。富文本的优先级为：字段的明确段落对齐 > 原正文段落格式 > 行默认。隐藏或空的行首字段保留行规则；拖动合行采用目标行规则，另起一行保留来源行规则。

## 发现并修复的问题

- 窄栏换行后，PDF 旧的末尾字段外边距会使一行居中偏左 **3pt（约 4px）**。改用 gap 后，在验收样本中误差降至 0.001pt 以下。
- 带底色侧栏有内边距，HTML 拖动参考线原来使用外层栏宽，相对实际内容区会相差 **5.25pt（7px）**。现在参考线使用内容区边界，视觉行的对齐也按该边界验证。
- 隐藏行首字段时，设置面板原来可能显示为继承默认。现在读取完整逻辑行再显示覆盖规则。
- 对齐后的 HTML 列表如果继续使用外置标记，项目符号会停在左侧。对齐覆盖生效时，将标记纳入首段的行布局，与 PDF 的行为保持一致。

## 验证结果

| 检查 | 结果 |
| --- | --- |
| 单元测试 | 37 个文件、231 项通过；新增 6 项对齐规则测试、8 项 HTML 对齐测试 |
| 前端与云端类型检查 | 通过 |
| 对齐矩阵 | 14 组：字段、行、模块覆盖、隐藏/空行首、富文本继承/覆盖、左右侧栏、跨页长文 |
| HTML 坐标 | 15 页、153 个字段、15 个对齐断言；最大偏差 **0.005pt** |
| PDF 坐标 | 15 页、15 个对齐断言；偏差均小于 **0.001pt** |
| 独立 PDF 文本检查 | 8 个段落坐标断言；170 段重复长文完整；0 个字符越出 A4 |
| 原有导出回归 | 27 组、73 页、191 次模块内容比较，0 失败 |
| 长侧栏回归 | 10 页、46 个字段；0 行截断，开关拖动模式保留正文与分页 |
| 浏览器操作 | 拖动合行并靠右、仅对齐、模块范围、一键撤销、设置面板同步与取消、Enter/Escape、保存刷新、单字段模块、精确 PDF 更新 |
| 手机宽度 | 375px 下工具栏无横向溢出，对齐对话框完整可操作 |

对齐矩阵在本机 Chrome、字体已就绪时，字段坐标计算耗时 **0.3–1.0ms**，分页计算 **1.0–1.5ms**。十页长侧栏单次字段测量为 **7.1ms**。这些是计算时间；浏览器后台标签页的 requestAnimationFrame 被节流，矩阵中 3.0–3.9 秒的调度等待不能代表前台交互延迟。普通预览下不测量字段坐标；对齐继续使用即时 HTML，无需先生成 PDF。

## 复现

- pnpm test
- pnpm --dir cloud typecheck
- pnpm build:cloud
- pnpm exec tsx scripts/verify-preview-alignment.ts
- python -X utf8 scripts/verify-preview-alignment.py
- pnpm exec tsx scripts/verify-stage4-exports.ts
- python -X utf8 scripts/verify-stage4-exports.py
- pnpm dev 后打开 /tests/browser/preview-alignment.html 点击「开始验证」
- 长侧栏：/tests/browser/instant-preview-drag.html?case=double-left-long-sidebar

合成 PDF、HTML、JSON 样本、原始测量和截图输出到 output/preview-alignment/。该目录不进 Git，脚本与样本定义随功能提交。
