# 预览点击定位

2026-11-04 更新。实时预览按整个内容模块强调，点击后切换到内容编辑、滚动到对应模块，并聚焦第一个输入区域或条目。基本信息不显示强调区域，也不通过预览定位编辑。窄屏同时切回编辑视图。模块编辑卡片短暂显示描边，帮助确认当前位置。

## 坐标与显示

PDF 排版时为各内容模块保留稳定标识，从 react-pdf 的实际分页布局读取区域，基本信息标识不进入交互区域。在合并主栏、侧栏和手动页时同步转换为最终 A4 的页号与顶左坐标；预览再按当前缩放换算。跨页模块在每页保留自己的强调区域。

区域元数据随渲染结果返回，不写入简历备份。画布和区域使用相同的纸页尺寸，纸页描边不占布局宽度。靠近页顶的提示显示在区域内，避免缩小时被裁掉。PDF 尚在更新时关闭旧区域的点击入口，历史预览保持只读。邮箱与网站链接显示在强调区域上层，可正常打开。

## 验证

首轮验收为 61 个 Vitest 用例；2026-11-04 回归为 111 个用例，类型检查及生产构建通过。预览区域的 6 项测试覆盖分页、祖先坐标、左右栏偏移、裁剪、无效数据、同页片段合并和基本信息排除。

| 浏览器操作 | 核验结果 |
| --- | --- |
| 点击技能预览 | 内容面板定位 `section-skills`，聚焦 React 条目 |
| 点击第二页项目 | 对应区域页号为 2，内容面板定位 `section-projects` |
| 在模板面板点击教育预览 | 切换为内容编辑，定位 `section-education` |
| 基本信息预览 | 不显示强调区域，点击不定位编辑 |
| 768 px 宽度点击项目预览 | 自动切回编辑视图并定位项目 |
| 保存新模板并刷新 | Modern Split 仍为选中状态 |
| 下载实际 PDF | 两页、院校和专业保留，无 NUL 或超出 A4 的文字 |

交互使用明确标记为示例的虚构简历。截图和实际下载文件保存到被 Git 忽略的 `output/template-review/`；模板定义见 [模板目录](../src/domain/templates.ts)，当前开发与验证范围见 [开发记录](development-log.md)。
