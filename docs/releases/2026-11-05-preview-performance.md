这些是当前生产版本的一次端到端观察。首次打开和首次字体加载仍然很慢，现有证据不支持“线上秒开”的结论。

测试期间同时存在 Git 大文件上传和 HTTP 字体下载，未测量独立网络吞吐，也未分离下载、解压、PDF 排版与 canvas 绘制各阶段耗时，因此不能将延迟全部归于网络。没有优化前正式站在相同条件下的 A/B 数据，也没有多轮分布，不能由这些数字计算线上优化百分比。部署前的本机 246／793／337 ms 样本具有不同网络及缓存条件，不能直接作为这次线上测试的对照组。

后续需要固定设备与浏览器、暂停其他传输、分别测量冷缓存和热缓存，并保留请求及渲染阶段记录，才能判断剩余瓶颈及改进幅度。
