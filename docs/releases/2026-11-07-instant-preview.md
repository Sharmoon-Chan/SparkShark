## 本次线上耗时

在当前设备、Chrome 156.0.8078.80、1440×980 视口，使用默认虚构 2 页简历，无照片；真实公网，无人工限速或 CPU 限速。上传及 HTTP 批量检查已完成后才计时。每个冷／热缓存条件各 3 次，报告中位数与范围，不报告 p95。

| 条件 | 首个预览中位数（范围） | 字体稳定中位数（范围） |
| --- | ---: | ---: |
| 浏览器冷缓存 | 348.9ms（325.2–447.2） | 519.4ms（513.3–933.4） |
| 浏览器热缓存 | 276.0ms（269.7–377.0） | 401.8ms（383.7–490.1） |

冷缓存通过 CDP 清空浏览器 HTTP 缓存，不清空 Cloudflare 边缘缓存；此前功能与资源检查可能已经预热边缘。三次冷缓存均实际传输了约 1.875 MB 子资源，不能将这个结果当作所有地区、网络和设备的保证，也不能据此和 11 月 5 日不同测试条件的一次结果计算加速倍数。

导入功能测试中，约 69 KB 的虚构 PDF 首次解析器加载至核对结果为 2373ms，随后两次为 112／103ms；约 3.9 KB 的 DOCX 首次为 1356ms。计时从选择本机文件到核对结果，首次包含对应解析器下载。文件规模和缓存条件特定，不能代表所有简历。

16 模板功能脚本中的一次模板切换为 272ms，含自动化点击等待，作为单次观察保留。前述网络、导入和模板计时测量范围不同，不混作同一性能指标。模拟慢网下首次字体仍约 10.45 秒的发布前结果保留在第四阶段记录中。
