# 字号联动与模块层级修正

2026-11-07。修复“页面字号变大后，部分模块仍很小”的问题，已发布并在用户指定简历上核验。本次只记录排版参数，复现与导出用合成简历，不把用户简历内容加入仓库。

## 原因与参考

受影响简历的页面字号为 13px，技术项目的项目名／简介／详情分别保留了 12.5／10／12px 的旧版独立值；个人技能没有覆盖值，沿用页面计算。因此调页面字号时两边失去同步，项目标题甚至比辅助文字小。读取的 DOM 字体均为思源黑体，字体状态 ready、缺字为 0；本次证据不支持“两个模块选择了不同字体”的判断。字号、字重和颜色会改变视觉感受。

核对 TalenCat 的公开 [Preview 构建](https://assets.talencat.cn/web/assets/Preview-YgWaN82q.js)、[Builder 构建](https://assets.talencat.cn/web/assets/Builder-BovMmq-c.js)和[样式表](https://assets.talencat.cn/web/assets/main-Dw55IjuP.css)：页面字号写入 `--resume-font-size`，普通内容继承基准，语义 h2／h3 使用约 20/14 与 18/14 的 em 比例。部分模板另有固定 rem 工具类，不能宣称全部模板均同比缩放。本项目借鉴统一基准与相对层级，将条目标题从 16/14 提高到 18/14。

## 新规则

- 页面字号是正文基准。模块标题／条目标题／正文默认比例为 **20／18／14**，HTML、PDF、模块设置示意与智能一页共用计算。
- 模块输入仍显示当前实际 px，修改时保存 `fontSizeRatio`，即当前字段字号与页面正文基准之比。之后改变页面字号、密度，或智能一页调整字号，字段同比变化。
- 老备份的 `fontSizePx` 可继续读取，不在打开时静默改写。在改变页面字号时，以改变前的页面基准转换为比例，保留原来相对大小；不再积累逐次缩放舍入误差。比例与旧 px 不可同时存在，前后端共享同一校验。
- “统一本模块字号”只修改对话框草稿；取消不应用。“统一全篇字号”先保存历史，确认后仅清除字号覆盖，保留字段顺序、显示、对齐、间距、斜体／下划线及正文格式，提供撤销。
- 页面设置显示三层实际字号和自定义字段数量；模块设置显示实际字号、百分比及恢复层级入口。字号示意使用与纸张相同的字体交付方式，包括用户设置的斜体。
- 新版 PDF 缓存标识为 `linked-typography-20`。
